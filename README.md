# RacePoint-Live-Releases

Official Windows x64 application releases and automatic updates for RacePoint Live.

**[Download the Latest release](https://github.com/SteveMcGitub/RacePoint-Live-Releases/releases/latest).** Choose the RacePoint Live application ZIP, not GitHub's source-code archives.

For a new portable installation, extract the complete ZIP and run **RacePoint Live.exe** inside the **RacePoint Live** folder. Keep **Updater**, **StarterContent**, and the other included files together. The .NET runtime is included; Visual Studio is not required.

Existing users can check **Help / Updates** for a newer signed release and choose when to install. Close broadcast graphics and disconnect iRacing/replays before updating. Existing championships, profiles and settings are preserved; do not reset user data to upgrade. Follow **README-FIRST.txt** in the ZIP for the managed launcher used after the first portable update.

Windows SmartScreen may show a reputation warning because the executable is not Authenticode-signed. Automatic updates verify the separate production release-manifest signature and package checksums.
